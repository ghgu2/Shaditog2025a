# 📚 Bookstore Backend API

Backend-сервис для хранения информации о 📖 книгах и 🧑‍💼 продавцах, построенный на [FastAPI](https://fastapi.tiangolo.com/).

---

## 🚀 Возможности

- Управление книгами (добавление, обновление, удаление, просмотр информации)
- Управление продавцами (добавление, обновление, удаление, просмотр информации)
- Работа с базой данных (SQLAlchemy)
- Pydantic-схемы для валидации
- Готовность к Docker и миграциям (Alembic)
- Тесты (pytest)

---

## 🛠️ Технологии

- **FastAPI** — фреймворк для создания API
- **SQLAlchemy** — ORM для работы с БД
- **Alembic** — миграции
- **Pydantic** — валидация данных
- **Docker** (опционально)
